## Remaining real-world gates (not papered over)
Actual masters, native model controls, costs, per-model temporal quality and seam
feasibility must be observed. Audio source requires user authorization. Generative
endpoints may only approximate the requested still; if real clips cannot meet the
boundary contract, reject/escalate rather than overwrite frames to hide a jump.
CI is not art direction, identity/flow detection, proof that a claimed user approval
is authentic, or server-side tamper-proof branch protection. Maintainers must enable
required CI/PR protections if enforcement against intentional bypass is desired.
Nothing in this change certifies any clip; all generation and review gates start pending.
